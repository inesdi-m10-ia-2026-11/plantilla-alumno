# Tu cuaderno del Módulo 10

Este es tu repo de gestión: el cuaderno de tu proyecto. Aquí va lo que decides y lo que aprendes. El código de tus apps va en los repos de tu cuenta de GitHub (el de la sesión 1, con `web/`, es el primero).

**Quién lo ve:** tú y el docente. Es privado: el resto de la clase no lo ve.

| Archivo | Qué va | Cuándo |
|---|---|---|
| `idea.md` | Tu idea en una frase y qué predices | Sesión 1, y cada vez que cambie |
| `brief.md` | El proyecto en una página: problema, usuarios, objetivo, alcance, criterios de éxito, restricciones e hitos | Sesión 2, y cada vez que cambie el alcance |
| `datos.md` | Fuente, licencia, columnas y qué columna predices | Sesiones 1 y 2 |
| `arquitectura.md` | Las piezas, cómo se conectan, dónde vive cada una y la pieza actual en detalle | Sesión 2, y cada vez que añadas una pieza |
| `estado.yaml` | Dónde está cada pieza (pendiente, en curso, hecho, bloqueado), con su URL. Esquema fijo | Al final de cada sesión, con tu agente |
| `todo.md` | Las tareas de la sesión actual | Al empezar y al acabar cada sesión |
| `decisiones.md` | Cada decisión importante, con fecha y por qué | Cuando decidas algo |
| `bitacora/` | Una nota por sesión: qué pediste a la IA, qué falló y cómo lo arreglaste | Al final de cada sesión, 5 minutos |
| `prompts/` | Los prompts que te funcionaron | Cuando uno te funcione |
| `urls.md` | Tus URLs (web, API, MCP, agente) y tus repos de app | Cada vez que publiques algo |
| `apps/` | Tu repo de app, enlazado como submódulo | Desde la sesión 1 |

## Cómo usarlo con tu agente

1. Clónalo en tu portátil, junto a la carpeta de tu proyecto (cambia `ESTE-REPO` por su nombre):
   ```bash
   cd ~
   git clone https://github.com/inesdi-m10-ia-2026-11/ESTE-REPO.git
   ```
2. Al acabar cada sesión, abre la carpeta con tu agente y pídele:
   ```
   Lee AGENTS.md. Hoy ha sido la sesión N. Hazme preguntas una a una y
   escribe bitacora/sesion-0N.md con lo que te cuente.
   ```
3. Revisa lo que ha escrito, y commit y push.

La bitácora te ahorra trabajo el 3/12: el documento de autoevaluación sale de aquí.

## Reglas

- Ninguna clave, contraseña ni token, ni aquí ni en ningún repo.
- Sin datos personales de nadie. Si tus datos son de tu empresa, describe las columnas; no copies filas.
